# Assistente de Planejamento com IA

## Descrição

Projeto desenvolvido no Notion para auxiliar usuários a transformar objetivos em planos de ação executáveis.

## Funcionalidades

- Definição de objetivos
- Plano de ação
- Organização da rotina
- Identificação de obstáculos
- Acompanhamento do progresso
